# Evidence and sources

Keep a register: `ID | file/URL | title | date and version | parts read | limits`. Preserve original file names and work on copies. Update affected conclusions when the package changes. Keep separate project cards and calculation bases for different lots or objects; do not transfer prices, quantities or dates. Do not combine lots without a request to compare them.

Use verifiable coordinates. PDF: file ID, PDF page, printed page and clause when known. DOCX: heading, clause, table and row; give page only if checked in a rendering. XLSX: sheet, cells and item; distinguish formulas from values and do not treat stale cached values as verified. Drawings: drawing code, sheet, detail and section. User statements: U01, message date, and whether fact, limit or scenario. If a source has no numbering, use a heading, exact row or cell, or a short quotation with the file name. State when coordinates cannot be recovered. Never invent them.

| Status | Meaning |
| --- | --- |
| Confirmed | Direct source statement; cite it. |
| Calculation | Reproducible result; show inputs and formula. |
| Inference | Consequence of established facts; explain the link. |
| Assumption | Hypothesis or scenario; state the condition and verification. |
| No data | Gap in the reviewed package and its effect. |
| Conflict | Both records and sources; do not average them. |
| Not applicable | Explain why; do not use for missing data. |

A missing term in the available material is not proof that an obligation does not exist. Distinguish a document that is missing, unreadable, or read without finding the information. Distinguish a cited statement that no advance is provided from missing advance information.

Use R01 for risks, Q01 for questions, and A01 for actions. Record each risk as condition or gap, evidence, consequence, justified level, measure, owner and closure condition. For missing data cite the source register, not an invented clause. High risks can prevent eligibility, delivery or acceptance, or materially change price, funding, schedule or liability; explain the mechanism. Medium risks need clarification or cost and have a specific control. Low risks have limited impact with ordinary control supported by the facts. State evidence sufficiency separately. Uncertainty does not prove high probability. Use numeric probability, penalties or reserves only with a basis; an unknown amount is not zero risk.

Compare specifications, design, quantities, estimates, schedule, contract and clarifications for the same sections and versions. Check diameters, lengths, work, quantities, dates, warranty, VAT, payment and security. Establish document priority from evidence, not assumption. For unresolved conflicts, show both sources and possible consequences without selecting an unsupported figure. Put critical conflicts in participation conditions and customer questions.
