# Анализ закупок и подрядных проектов

Навык Codex для анализа тендерной документации и подготовки рекомендации об участии в закупке. Он подходит для строительных, ремонтных и инфраструктурных проектов, включая работы на трубопроводах и бестраншейные технологии. Анализ ведётся по предоставленным документам и данным компании.

## Что делает навык

- Проверяет требования закупки, техническую реализуемость, смету, финансирование и условия договора.
- Отделяет подтверждённые факты от расчётов, предположений, противоречий и отсутствующих данных.
- Сводит результаты в единый отчёт на русском языке: резюме, семь разделов, риски, вопросы и следующие действия.
- Использует специализированные роли и независимую проверку, когда делегирование разрешено и доступно. Иначе выполняет проверки последовательно и сообщает об ограничении.
- Не считает отсутствие документов доказательством отказа от участия и не подменяет неизвестную себестоимость нулём.

## Установка в Codex

Клонируйте репозиторий в каталог навыков:

```bash
git clone https://github.com/mrzert/analyze-procurement.git "${CODEX_HOME:-$HOME/.codex}/skills/analyze-procurement"
```

Перезапустите Codex, если новый навык не появился в текущем сеансе. Передайте закупочные документы и, по возможности, сведения о специализации и ресурсах компании. Пример запроса:

```text
Используй $analyze-procurement. Проанализируй приложенную закупочную документацию и подготовь заключение об участии.
```

Если сведений о компании недостаточно, навык отметит это и продолжит другие проверки. Внешний поиск и отправка сообщений выполняются с учётом инструкций пользователя и правил среды.

## Структура

- `SKILL.md` — назначение, границы и порядок анализа.
- `agents/openai.yaml` — описание навыка для интерфейса.
- `assets/report-template.md` — постоянный шаблон отчёта на русском языке.
- `references/agent-briefs.md` — задания специалистов и рекомендуемые модели и усилия.
- `references/evidence.md` — источники, статусы утверждений и риски.
- `references/calculations.md` — правила расчёта стоимости, маржи и денежных потоков.

Модель и усилие применяются только тогда, когда среда позволяет их задать. Шаблон фиксирует структуру, но не гарантирует одинаковый текст или достоверность выводов: они зависят от исходных документов и качества проверки.

## Язык инструкций

Английские инструкции упрощены с учётом принципов ASD-STE100 Issue 9. Полное соответствие стандарту не подтверждено: автоматическая проверка охватывает только часть правил, а словарь не проверен полностью. Предоставленный стандарт не входит в репозиторий.
